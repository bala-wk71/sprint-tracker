# Testing Strategy

## Visual Verification (Playwright MCP)
Use Playwright MCP after each feature to:
1. Navigate to the relevant page
2. Screenshot to verify layout and styling
3. Fill forms, click buttons, verify state changes
4. Reload page to confirm data persistence
5. Test at multiple viewport widths (375px, 768px, 1440px)

## Manual Testing Flow
For each phase, test the full user flow:
- Morning check-in -> time logging -> evening wrap-up
- Sprint setup -> daily tracking -> week summary
- Invite flow -> reviewer access -> comments
